# 32: Share pinned to a Version or following the latest

**What to build:** When creating a Share, the Diagram Owner chooses whether it always shows the latest Version or stays pinned to a specific one.

**Blocked by:** 12 (Diagram Owner takes over the Author's powers)

**Status:** ready-for-agent

- [ ] A Share can be created following the latest Version (the default, and the current behaviour) or pinned to a chosen Version.
- [ ] The Public Viewer, and downloads when allowed, serve the pinned Version's content for pinned Shares.
- [ ] The Shares list shows which Version each Share is pinned to, if any.
- [ ] Feature tests: a pinned Share keeps serving the old content after new saves, and a latest Share serves the new content.
