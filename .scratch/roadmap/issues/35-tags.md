# 35: Tags

**What to build:** Anyone who can edit a Diagram applies or removes global Tags, and anyone can filter the list by Tag.

**Blocked by:** 34 (Filters and pagination on the Diagram list)

**Status:** ready-for-agent

- [ ] Tags are global and created implicitly on first use; names are unique.
- [ ] Anyone who can edit a Diagram (Diagram Owner, Collaborator, Member) can apply and remove its Tags; others are refused.
- [ ] The list shows each Diagram's Tags and can be filtered by Tag, without revealing hidden Diagrams.
- [ ] Feature tests for applying, removing, permission refusal and filtering.
