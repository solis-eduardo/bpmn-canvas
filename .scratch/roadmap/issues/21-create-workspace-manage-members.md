# 21: Create a Workspace and manage its Members

**What to build:** Any User creates a Workspace, becomes its Workspace Owner, and adds or removes Members; Users see which Workspaces they belong to. An Administrator can manage any Workspace.

**Blocked by:** 12 (Diagram Owner takes over the Author's powers)

**Status:** ready-for-agent

- [ ] Any User can create a Workspace and becomes its Workspace Owner (and a Member).
- [ ] The Workspace Owner and Administrators can rename the Workspace and add or remove Members; other Members can't.
- [ ] Users see the list of Workspaces they're Members of.
- [ ] `CONTEXT.md` terms (Workspace, Member, Workspace Owner) are used on screen.
- [ ] Feature tests cover creation, membership management by Workspace Owner and Administrator, and refusal for plain Members.
