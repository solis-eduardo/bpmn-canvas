# A User may hold multiple Locks

A Lock belongs to one Diagram, so a User may hold Locks on multiple Diagrams at once. Navigation and closing the Editor never release a Lock by themselves: a Lock is released explicitly by its holder or an Administrator, or by expiry after 3 minutes without a Heartbeat (ADR-0003), which saves any unsaved content as a provisional Version. Each Lock expires independently, so a User keeping one Editor active does not keep their other Locks alive. A different editor may request a held Lock and notify its holder, but the request never triggers an automatic transfer, regardless of elapsed time. This avoids silently releasing a Diagram when its editor changes screens and keeps the transfer decision with an authorized actor.
