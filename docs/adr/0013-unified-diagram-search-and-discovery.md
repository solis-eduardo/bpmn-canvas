# Unify Diagram search and discovery

Use one search form and one paginated results table for Diagrams a User can open and out-of-Workspace Diagrams they can discover. Search applies to openable Diagram titles, Slugs, and BPMN content, while discoverable Diagrams match by title only and expose only their title, Diagram Owner, and access-request action; workspace-hidden Diagrams remain absent. Existing filters continue to narrow openable results, and legacy `discover` query URLs redirect to the unified `q` search. This preserves the request-access path while removing the separate discovery entry point described in ADR-0010.
